# Goodness Chizurum Nwafor — CSM/TAM Portfolio

A polished React + Vite portfolio built from the supplied resume, assignments, case studies and work-sample files.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Important attribution rule

Individual assignments are labelled as individual work. Group case studies are labelled as group projects. The site does not claim group work as individual authorship.
